# Jordan Houri — GitHub Pages personal site

Version 105 refines the orbit navigation chevrons.

- chevrons are shorter than v104
- chevrons are wider and heavier so they read clearly as arrows
- desktop stroke width is 4px
- angle is increased to 10 degrees
- controls are no longer inside any scrollable orbit-card content
- one fixed pair now lives in the orbit viewport and tracks the active panel's
  projected left/right edges as the cylinder rotates
- scrolling panel content therefore never moves the arrows

All orbit geometry, responsive sizing, text-selection behavior, particles,
card blur, sharp corners, and mobile scroll behavior remain unchanged.
